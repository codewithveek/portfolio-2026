DriftWatch wraps an agent built on the **Vercel AI SDK**. Every tool call and model step becomes an **OpenTelemetry** span, so the agent's behaviour shows up in SigNoz or any OTLP backend next to the rest of the system.

A **drift watcher** reads Prometheus metrics built from that telemetry and looks for behavioural drift: changes in the tool-call mix, error rate, latency and token spend.

When drift crosses a policy, **`@driftwatch/autopilot`** responds. It can notify, pause, roll back or throttle, and destructive actions wait for a human to approve them. `@driftwatch/server` and `@driftwatch/console` give the team a place to see and act on it.

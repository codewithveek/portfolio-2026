The base layer is **`@afriex/sdk`**, the official TypeScript SDK for the Afriex Business API: customers, transactions, payment methods, balances, rates and webhooks. The repository lives in Afriex's GitHub organisation; Lucky maintains the npm package.

On top of it sit two commerce plugins. **`medusa-payment-afriex`** adds bank transfer and Afriex Checkout to Medusa v2 stores, verifies webhooks and can be switched on per region. The **Afriex Gateway for WooCommerce** brings the same to WordPress, in classic and block checkout.

The **reference apps** are the code behind the guides. The digital marketplace pairs a Fastify, PostgreSQL and Drizzle backend for checkout and creator payouts with a Next.js storefront (Tailwind CSS, React Hook Form, Zod, TanStack Query), and is written up as the two-part *Build a Digital Marketplace with Afriex, Fastify and Postgres* series.
